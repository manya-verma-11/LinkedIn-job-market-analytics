# LinkedIn Job Market Analysis & Career Insights

## Project Overview

This project analyzes LinkedIn job-posting data to understand job market trends, work types, remote opportunities, applicant patterns, company activity, and career-related insights.

The project follows an end-to-end data analytics workflow, including data cleaning, exploratory data analysis, visualization, machine learning, model evaluation, and an interactive Streamlit dashboard.

## Dataset

**LinkedIn Job Data — Analysis of Indian Job Market**

Kaggle Dataset:
